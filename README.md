# 🛒 Amazon Clone Project
"A simple frontend clone of Amazon's homepage using HTML, CSS"
This is a basic front-end clone of the Amazon homepage built using **HTML** and **CSS**. 

## 🚀 Features
- Amazon-style navigation bar
- Category and product display sections
- Image cards with hover effects
- Organized and reusable CSS classes

## 🔧 Technologies Used
- HTML5
- CSS3
